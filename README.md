# Project_Palirates
한국공대 2025년도 졸업작품


 C++ 방식 최대한 활용할 것
------------------------------------------------------------------------------------------------
- 객체를 shared_ptr로 관리
- 컨테이너 vector로 변경
- 문자열 string_view 활용


주의 사항
------------------------------------------------------------------------------------------------
- 커밋 할때, 파일의 인코딩 형식 확인할 것
- UTF-16 계열인 경우, UTF-8로 변환 할 것 // 깃에서 파일이 바이너리로 읽히게 되는 원인

- 사용할 조명이 많아질 경우, Deffered Lighting 최적화 할 것 // 테셀레이션을 이용하여, 조명 영역을 구하고, 영역에 포함되는 픽셀에서만 조명 연산하는 방식

- Object::Render 에서 계층 구조 따라 갈때, Active에 의한 동작 전환이 이상해보임 - 검토 필요

진행 상황:
------------------------------------------------------------------------------------------------
그림자 품질 문제의 발생 조건 파악 완료
- 현재 씬에서 0,0 좌표에 가까워질수록, 그림자의 품질이 높아지고, 멀어질수록 품질이 저하되는 중
--> hlsl 상에서 그림자 구현 방식 자체에는 큰 문제가 없고, CPU 상에서 만들어서 전달한 view-projection 행렬에 문제가 있다는 것

행렬 만드는 구조를 수정해야 함

할 일
------------------------------------------------------------------------------------------------
그림자 품질 문제 해결하기
서버에 충돌 검사 추가하기

그림자 품질 문제 원인 발견 및 처리(임시) 완료

원인: G-Buffer에 픽셀의 WorldPos를 직접 저장하여 활용하던 방식으로, 좌표 값이 커지자, 정밀도 오차 발생
-> 정밀도 오차로 인해, 픽셀에 저장된 World_pos의 절댓값이 커질수록 오류가 선형적으로 나타나고 있던 것

해결책:
	- 1. World_pos 저장하는 G-Buffer 포맷을 DXGI_FORMAT_R32G32B32A32_FLOAT 로 크기 16 -> 32  변경 // 현재 임시로 적용하여 처리했음
	- 2. View_Z 값을 이용하여, NDC 위치에서부터 invView, invProj 를 적용하여, 값을 복원
		-> 연산량 증가 <--> 메모리 비용 절약
		-> View_Z로 후처리 및 안개 효과에 활용 가능


현재는 1번 방법으로 적용하였음, 추후 2번 방법으로 수정할 예정
