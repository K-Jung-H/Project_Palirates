#Server_Project README
-------------------------
#Project_Palirates_Server
-------------------------
한국공대 2025년도 졸업작품


#기존 구조에서 개선된 사항
------------------------------
TCP 네트워크 기반 서버 구축

씬 및 오브젝트 관리 기능 추가

클라이언트 간 데이터 동기화를 위한 브로드캐스트 기능

불필요한 패킷 전송을 방지하는 최적화 적용

데이터 유효성 검사 및 보안 강화

#현재 진행 내용
-------------------
Server - 네트워크 관리 및 클라이언트 연결 처리

Scene_Manager - 씬(Scene) 개별 관리 및 플레이어 위치 동기화

Object_Manager - 서버 내 오브젝트 상태 관리

Monster_Manager - 몬스터 생성 및 상태 관리

Logger - 서버 로그 기록 및 디버깅 지원

DatabaseManager - MySQL 연동을 통한 좌표 저장 및 불러오기 (미적용)

#작업 목표
-------------------
서버 네트워크 안정성 및 최적화

 TCP 소켓을 활용한 서버-클라이언트 간 통신
 
이동 데이터 패킷 최적화 (중복 전송 방지)

비정상적인 패킷 차단 (유효성 검사 추가)

다수의 클라이언트가 동시에 접속할 경우 멀티스레드 성능 개선

#진행 상황
------------
네트워크 동기화 및 패킷 관리

서버가 클라이언트의 패킷을 정상적으로 수신하는지 확인

클라이언트 간 데이터 동기화 및 씬(Scene) 업데이트 구현

서버가 클라이언트의 위치를 검증 후 정상적인 데이터만 반영하도록 수정
