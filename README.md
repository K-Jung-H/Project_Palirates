# Project_Palirates
한국공대 2025년도 졸업작품


 C++ 방식 최대한 활용할 것
------------------------------------------------------------------------------------------------
- 객체를 shared_ptr로 관리
- 컨테이너 vector로 변경
- 문자열 string_view 활용


주의 사항
------------------------------------------------------------------------------------------------
- 사용할 조명이 많아질 경우, Deffered Lighting 최적화 할 것 // 테셀레이션을 이용하여, 조명 영역을 구하고, 영역에 포함되는 픽셀에서만 조명 연산하는 방식


주의 사항
------------------------------------------------------------------------------------------------
- 카메라 조종 방법: W/A/S/D
 
- 배 조종 방법: I/J/K/L

- 카메라 토글: 1/2/3/4/5/6

- 씬 전환 : TAB
