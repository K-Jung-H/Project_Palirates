진행 상황:
------------------------------------------------------------------------------------------------
- 서버와 클라이언트 배(스테이지 선택) 동기화 완료
- 서버 자체에 클라이언트에서 사용하던 것과 같은 구조의 Timer 추가 완료
- 각 클라이언트와 마지막으로 주고받은 패킷의 내용을 변수로 저장하여, 출력하는 기능 추가 // 디버깅 용도

- 이제 각 클라이언트의 씬 정보에 맞는 데이터를 전달함

ex:
0 번 플레이어: 배 씬
1 번 플레이어: 캐릭터 선택 씬 -> 0번 플레이어가 선택한 캐릭터 정보가 유지되어 있음
-> 서버에서 입력에 따른 씬 별 다른 동작 적용 및 전달


주의할 점:
- 한명은 캐릭터 선택 씬인데, 스테이지 선택이 되어 버리면? -> 캐릭터 선택 중인 플레이어가 선택 완료 후, 스테이지 선택을 완료 해야, 인-게임 전환이 되게 되어 있음
	-> 현재 접속중인 플레이어 인원이 모두 ready가 되어야 씬 전환 되기 때문 == 의도된 동작, 문제 없음

- 다른 플레이어는 이미 인-게임 상태인데, 새로운 플레이어가 캐릭터 선택을 마치면? -> 바로 인게임 진입 == 의도된 동작, 문제없음

- 인게임까지 진입한 플레이어가 게임을 종료 후, 새로운 플레이어가 접속하면? -> 플레이어 선택이 끝나자마자, 인게임으로 전환되어 버림
	-> 이전 플레이어들의 데이터는 사라지지만, active_scene으로 설정된 씬의 상태는 유지됨 == 문제 상황

==> 활성화된 플레이어가 없다면, 모든 씬 데이터를 초기화하고, 대기 상태 진입
