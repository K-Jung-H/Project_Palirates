# Project_Palirates
한국공대 2025년도 졸업작품


기존 프레임 워크를 C에서 C++ 방식으로 변경 중
------------------------------------------------------------------------------------------------
- 객체를 shared_ptr로 관리
- 컨테이너 vector로 변경
- 문자열 string_view 활용



현재 진행 내용:
===================================================================
- Scene_Manager
- OBB_Drawer
- Text_UI_Render
- Text_UI_Manager
- Tile_Map


진행 목표:
- 타일에 따른 객체들 컬링 로직 개선
- 다른 플레이어가 연결되어 있다면, 해당 플레이어 랜더링하기

진행 상황
------------------------------------------------------------------------------------------------
- 좌표에 따라 하이트맵에서 높이, 노멀 값을 읽어, 사물 재배치 기능 추가 완료
- 객체들의 위치에 따른 타일이 포함하고 있는 객체 리스트 분류 완료
- 프러스텀 컬링을 통한 타일의 활성화 유무에 따라, 타일이 포함하고 있는 객체들도 함께 비활성화 처리하여 컬링 기능 추가 완료
