# Project_Palirates
한국공대 2025년도 졸업작품


 C++ 방식 최대한 활용할 것
------------------------------------------------------------------------------------------------
- 객체를 shared_ptr로 관리
- 컨테이너 vector로 변경
- 문자열 string_view 활용


주의 사항
------------------------------------------------------------------------------------------------
- 커밋 할때, 파일의 인코딩 형식 확인할 것
- UTF-16 계열인 경우, UTF-8로 변환 할 것 // 깃에서 파일이 바이너리로 읽히게 되는 원인

- 사용할 조명이 많아질 경우, Deffered Lighting 최적화 할 것 // 테셀레이션을 이용하여, 조명 영역을 구하고, 영역에 포함되는 픽셀에서만 조명 연산하는 방식

- Object::Render 에서 계층 구조 따라 갈때, Active에 의한 동작 전환이 이상해보임 - 검토 필요

문제점:
- 기존에  화면 전환 시 일부 발생하던 오류 발생 시점 발견 -> 윤곽선 처리 과정에서 발생
	- 마지막으로 사용했던 프레임의 데이터를 계속 반복해서 리소스로 재사용하는 구조의 문제
	-> 후처리에 사용하는 각 UAV를, 다시 사용하기 전에 초기화 하는 동작 추가 필요

-> 문제점을 해결하려면, 서술자의 CPU 핸들 값이 필요함, 그러나 기존 구조는 GPU 핸들만 저장 중
	-> 이를 해결하기 위해, 기존 힙 구조에 CPU 핸들를 저장하는 변수를 추가했지만, 문제 발생 
						// 하나의 힙에서는 GPU 핸들, CPU 핸들을 동시에 관리하면 안됨

// 아니면, 빈 버퍼를 만들어서, 해당 내용을 복사하도록 하여, 강제로 초기화 하도록 해도 됨 -> 매우 비효율적


시도할 해결 방법:
- 후처리 전용 셰이더에 각 CPU 핸들을 저장하는 구조를 별도로 추가하기
- 기존 힙에 추가로 저장하도록 하기에는 어려움이 있기 때문에, 사용할 수 없음


-> 줌 효과 완성하기
-> 윤곽선 블러 구조 오류 수정하기 
// 근데 다 같은 구조인데, 모션 블러에서는 괜찮고, 왜 윤곽선에서만 발생하는지 이유를 파악 못 함
