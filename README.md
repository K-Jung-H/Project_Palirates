1. 현재의 문제점
	1.1 두개 이상의 클라가 접속한 상황에서, 1개의 클라가 타임아웃으로 전송종료가 되면, 서버동작이 그대로 멈춰버려 다른 클라의 핑퐁도 받지 못하고 다른 동작도 안된다.
		1.1.1 추측 원인 : 서버에서 타임아웃 후 지우는 과정에서 교착상태에 걸렸다던가 충돌이 발생하였다 둘중 하나로 추측된다.
			해결책 : 재귀적 뮤텍스를 사용하거나 자원관리 타이밍을 사이에 한번 풀고 지우고 다시 락을 거는 형태로 바꾸어본다.
			-> 클라가 접속할때, 비어있는 가장 앞에 번호 쓰게한다.
