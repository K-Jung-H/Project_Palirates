# Project\_Palirates

한국공대 2025년도 졸업작품



## C++ 방식 최대한 활용할 것

* 객체를 shared\_ptr로 관리
* 컨테이너 vector로 변경
* 문자열 string\_view 활용



## 주의 사항

* 커밋 할때, 파일의 인코딩 형식 확인할 것
* UTF-16 계열인 경우, UTF-8로 변환 할 것 // 깃에서 파일이 바이너리로 읽히게 되는 원인
* 사용할 조명이 많아질 경우, Deffered Lighting 최적화 할 것 // 테셀레이션을 이용하여, 조명 영역을 구하고, 영역에 포함되는 픽셀에서만 조명 연산하는 방식
* Object::Render 에서 계층 구조 따라 갈때, Active에 의한 동작 전환이 이상해보임 - 검토 필요

문제점:

* 플레이어 위치 반영 안되고 있는 중 // Look벡터는 제대로 되고 있음
* 모델 동기화 필요 --> 이건 패킷에 모델 번호를 매번 보내게 해야 할 듯
* 다른 플레이어가 스테이지를 선택하여 인게임 씬이 상태에서 새로운 플레이어가 접속하면, 그 플레이어는 다른 플레이어가 보임
  but, 처음 접속하여, 함께 스테이지를 들어간 플레이어는 다른 플레이어를 못보고 있는 상황 발생

이상한 점은, 모든 플레이어는 서로 플레이어 변화를 받고 있다는 것

* 새로운 플레이어 진입
* 진입한 씬에 다른 플레이어가 미리 존재하던 경우
* 함께 씬에 입장하는 경우
* 플레이어가 퇴장하는 경우
  -> 해당 변화들을 클라이언트에서 제대로 탐지하고, Player 객체를 생성, 소멸 하고 있는 상태

디버그 결과, 생성된 플레이어의 객체가 렌더링 단계에 진입하는 것 또한 확인 되었음
렌더링이 호출 되고 있기 까지 한 상태에서 플레이어가 안그려지는 중.

서버에서는 제대로 씬 데이터에 플레이어가 저장되어 있고, 모든 플레이어에게 동일한 구조의 데이터를 전달 중

차이점은 플레이어의 씬 전환 시점.

* 데이터가 저장된 것이 확인 되고 있는데, 왜 안그려지는가?
