# Project_Palirates
한국공대 2025년도 졸업작품

현재 가장 최신분기


문제점

여러 클라이언트가 접속할수록, 클라이언트가 처리해야하는 정보의 양들이 많아저 큐가 넘치거나 클라에서 처리를 제대로 못하는 현상 발생

다른 플레이어들은 이제 보이나, T자 자세로 보이고 회전도 보이지 않는다.


해결 시도 과정

패킷의 구조를 바꾼다. state를 enum으로 받게, lookvector 내용도 추가한다.
  -> 이 경우 패킷의 용량이 늘어날수 있다.
  
패킷의 전송 속도를 늦춰본다. 딜레이를 주어 500ms, 혹은 100ms로 제한을 두어 큐에 쌓이는 양을 줄여본다.
  -> 지금 할수있는 가장 확실한 처리법이다. 0.5초, 0.1초정도의 딜레이는 사용자가 느낄 수준은 아닐것이라 예상된다.

현재 상태

패킷의 구조를 바꾸었고, 이를 각 객체들에 적용하기위해 구조를 바꾸는 중이다.

패킷의 전송 속도를 늦췄을때, 이 딜레이를 어디서 적용할지 여러 시도를 해본다. 서버 자체에서 딜레이를 줄것인지, 클라이언트에서 받을때 딜레이를 줄것인지. 전자가 나아보이긴 한다.


추후 할 일

몬스터, NPC도 지금 remote player처럼 서버에서 데이터를 받아 렌더링 할 수 있게 구조를 바꿔본다. 이 경우, 패킷의 양이 많아져 지금 문제를 해결하는것이 선행시된다.
