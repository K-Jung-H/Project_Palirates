
그림자 품질 저하 원인 분석 및 해결 결론
======================================

문제 발생 분석
------------------------------
- 카메라가 (0,0,0) 기준에서 멀어질수록 그림자 품질이 급격히 저하됨
- 그림자 텍셀 블러, 경계 뭉개짐, PCF 정확도 불안정 등의 현상 발생
- CSM 적용 이전의 기본 방향성 그림자 구현 단계부터 발생하던 문제


문제 원인 분석 요약
------------------------------
1) Snap / Texel 정렬
- snap 및 texel 단위 정렬은 정상적으로 적용되어 있었음
- snap 범위, 단위 변경 실험 결과 품질 변화 없음

2) Shadow View/Projection Matrix
- view/proj 행렬은 light 방향 기준으로 일관되게 생성됨
- light space AABB, 투영 영역 계산도 정상이었음
- Z 클리핑(MARGIN) 설정도 품질에 영향 없음

3) CSM 구조 자체
- cascade 개수 조절 실험 → 2개 이상 사용 시에도 문제 발생
- 각 cascade의 maxSize, texelSize도 위치에 따라 급변하지 않음

최종 원인
------------------------------
- 그림자 좌표 변환 연산: shadowCoord = mul(worldPos, LightViewProjTex)
- worldPos 값이 매우 커질수록 (예: 2500, 10000 이상)
- float × float matrix 연산 정밀도가 무너지며
- 그림자 샘플링 위치가 오차로 인해 흔들림
- 결과적으로 그림자 품질 급격히 저하됨

최종 해결 접근 방법
------------------------------
- worldPos 자체는 유지하되, "상대 위치 변환"을 적용해야 함

-> 기존 GBuffer 구조 변경 없이 해결 가능
-> CSM 구조 그대로 유지 가능
-> 대규모 월드에서도 정밀도 손실 없이 그림자 품질 유지


문제 접근 정리
------------------------------
snap 정렬 -> 정상
lightView/proj -> 고정 기준 생성
CSM 구조 -> 문제 없음
Z margin / size -> 영향 없음
worldPos * matrix 정밀도 -> 붕괴 (핵심 원인)
상대 위치 변환 -> 해결 핵심


-> 다음 접근 방법은 상대 위치 변환 적용하기

상대 위치 변환 적용하기-> 적용 결과, 문제 해결 안됨
